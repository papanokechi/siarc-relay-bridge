S22-04  check A6a is a tautology for any unimodular M with m11 != 0
  (1 + f1 f2)/alpha - m22  simplifies to  (-m11*m22 + m12*m21 + 1)/m11
  and equals (1 - det M)/m11:  0
  imposing det M = 1 (m22 = (1 + m12 m21)/m11):  0
  [PROVEN symbolically] the check cannot fail, hence tests nothing.
  [numeric arm] worst residual over 20 random unimodular M: 5.38713e-51

S22-05  the two orderings give different traces
  trace of diag*LOWER*UPPER (vdPS)      = (alpha**2 + f1*f2 + 1)/alpha
  trace of diag*UPPER*LOWER (this code) = alpha*f1*f2 + alpha + 1/alpha
  vdPS form equals alpha + (1+f1 f2)/alpha ?  True
  this form equals alpha(1+f1 f2) + 1/alpha ? True
  difference = f1*f2*(alpha**2 - 1)/alpha
  = (alpha - 1/alpha) f1 f2, non-zero unless alpha^2 = 1 or f1 f2 = 0.
  [PROVEN symbolically] the ordering is not a harmless relabelling.
  [numeric arm at the Stage-1 values (a,b) = (1/3, 5/7)]
    |this ordering  - 2cos(pi b)| = 1.14904e-29
    |vdPS ordering  - 2cos(pi b)| = 0.961216
  The corrected ordering holds; the one A7 originally used is off by O(1),
  reproducing the observed failure exactly.
